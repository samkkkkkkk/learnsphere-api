🚀 Reacting To Input With State 마스터하기 (중급)

📘 Core Concepts

React에서는 UI를 선언적인 방식으로 조작하며, 이를 위해 다양한 상태(state)를 관리합니다. 각 상태는 사용자의 입력에 따라 변경되며, 이로 인해 UI가 업데이트됩니다. 상태의 변화를 트리거할 수 있는 입력 유형은 크게 두 가지로 나뉘는데, 사용자 입력(휴먼 인풋)과 네트워크 응답(컴퓨터 인풋)입니다. 각 상태는 컴포넌트 내에서 useState 훅을 사용하여 관리하며, 각 상태의 변화를 통해 UI를 제어합니다.

상태를 관리하는 과정은 다음과 같습니다: 1. 컴포넌트의 다양한 시각적 상태를 정의합니다. 2. 상태 변화의 트리거를 식별합니다. 3. useState를 사용하여 메모리 내 상태를 표현합니다. 4. 불필요한 상태 변수를 제거하여 간결한 컴포넌트를 만듭니다. 5. 이벤트 핸들러를 연결하여 상태를 업데이트합니다.
