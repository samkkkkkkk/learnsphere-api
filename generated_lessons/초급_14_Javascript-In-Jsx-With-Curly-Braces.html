📘 Core Concepts

JSX는 JavaScript 파일 내에서 HTML과 유사한 마크업을 작성할 수 있게 해줍니다. 이로 인해 렌더링 로직과 콘텐츠를 같은 위치에서 관리할 수 있습니다. JSX에서 중괄호 {}를 이용하면 JavaScript 코드를 삽입하거나 변수와 함수 호출을 통해 동적인 콘텐츠를 참조할 수 있습니다.

가장 기본적으로, 중괄호를 사용하여 JavaScript 변수를 JSX 내에서 사용할 수 있습니다. 예를 들어, const name = 'Gregorio Y. Zara';라는 변수를 선언한 후,

{name}'s To Do List

형태로 이름을 표시할 수 있습니다.

또한, 중괄호 안에서는 JavaScript의 모든 표현식을 사용할 수 있으며, 객체를 생성하거나 인라인 스타일링에서도 유용하게 활용됩니다. JSX에서 객체를 사용하려면 style={{ backgroundColor: 'black', color: 'pink' }}와 같은 방식으로 중첩 중괄호를 사용하여 객체를 정의해야 합니다.

📝 Quiz

1. 문제: JSX에서 중괄호 {}의 용도는 무엇인가요?

정답: 중괄호는 JavaScript 코드를 삽입하여 변수 및 함수의 결과를 JSX 내에서 사용할 수 있게 합니다.

2. 문제: JSX의 인라인 스타일링을 적용할 때 어떤 형식을 사용해야 하나요?

정답: JSX에서 스타일링을 적용할 때는 객체 형식으로 중괄호를 중첩하여 사용해야 합니다. 예를 들어, style={{ backgroundColor: 'black', color: 'pink' }}와 같은 형식입니다.
