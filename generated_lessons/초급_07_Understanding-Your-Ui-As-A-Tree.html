🚀 트리로서의 UI 마스터하기 (초급)

📘 Core Concepts

React에서는 사용자 인터페이스(UI)를 트리 구조로 모델링합니다. 이는 브라우저의 HTML(DOM)과 CSS(CSSOM)와 유사합니다. UI 트리는 컴포넌트 간의 관계를 이해하고 상태 관리나 성능 최적화 같은 개념을 배우는 데 유용합니다. React 앱 내의 각 컴포넌트는 트리의 노드로 표현되며, 이들 간의 중첩 관계는 렌더 트리로 나타냅니다.

렌더 트리는 React가 단일 렌더링 시각화하는 컴포넌트 간의 계층 관계를 보여줍니다. 반면에, 모듈 의존성 트리는 앱 내에 존재하는 모듈 (파일)의 구조를 나타내며, 각 모듈이 어떤 모듈을 가져오는지를 시각화합니다.

이러한 트리 구조는 컴포넌트가 어떻게 서로 연결되어 있는지 이해하고, React 앱의 성능 또는 문제를 분석하고 최적화하는 데 매우 중요한 역할을 합니다.

📝 Quiz

1. 문제: React에서 UI를 어떻게 모델링하나요?

정답: React는 UI를 트리 구조로 모델링합니다. 이는 컴포넌트 간의 관계를 이해하는 데 도움을 줍니다.

2. 문제: 렌더 트리는 무엇인가요?

정답: 렌더 트리는 단일 렌더링에서 React 컴포넌트 간의 중첩 관계를 나타내는 트리입니다. 최상위 컴포넌트와 리프 컴포넌트를 식별하는 데 유용합니다.

3. 문제: 모듈 의존성 트리의 각 노드는 무엇을 나타내나요?

정답: 모듈 의존성 트리의 각 노드는 모듈을 나타내며, 각 가지는 해당 모듈의 import 문을 나타냅니다. 이는 컴포넌트와 로직이 서로 어떻게 연결되어 있는지를 보여줍니다.
