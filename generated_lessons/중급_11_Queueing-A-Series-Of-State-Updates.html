🚀 Queueing A Series Of State Updates 마스터하기 (중급)

📘 Core Concepts

"Batching"은 React에서 여러 state 업데이트를 한 번의 렌더링으로 처리하는 방법을 의미합니다. 일반적으로 state 값을 업데이트할 때 setState를 호출하면 React는 각 호출마다 새로운 렌더링을 요청하지만, batching을 통해 여러 호출을 하나의 렌더링으로 최적화할 수 있습니다. 이는 성능을 향상시킬 뿐만 아니라 중간 상태의 불필요한 렌더링을 피하는 데 도움이 됩니다.

또한 React는 이전 큐의 state를 기반으로 다음 state를 계산하는 updater function을 사용할 수 있도록 제공하여, 연속적인 state 업데이트가 가능하도록 하고 있습니다. 이를 통해 여러 번의 업데이트를 안전하게 처리할 수 있으며, 각 호출에서 마지막 상태를 사용할 수 있습니다.

📝 Quiz

1. 문제: setNumber(number + 1)을 세 번 호출할 경우 최종 상태는 무엇인가요?

정답: 최종 상태는 0입니다. 각 호출에서 number 값은 0으로 고정되기 때문에, 모든 업데이트가 완료될 때까지 상태는 변하지 않습니다.

2. 문제: batching이란 무엇이며, React에서 어떻게 작동하나요?

정답: Batching은 여러 state 업데이트를 하나의 렌더링으로 효율적으로 처리하는 방법입니다. React는 이벤트 핸들러 내의 모든 setState 호출이 끝난 후에 한 번의 리렌더링을 수행하여 성능을 극대화합니다.

3. 문제: 업데이트 후 상태를 변경하면 최종 상태는 어떻게 되나요?

정답: 마지막에 호출된 setNumber(42)는 이전 상태를 무시하고 42로 설정됩니다. 따라서 최종 상태는 42가 됩니다.
