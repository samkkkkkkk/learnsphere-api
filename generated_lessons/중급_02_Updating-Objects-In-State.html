🚀 Updating Objects In State 마스터하기 (중급)

📘 Core Concepts

React에서는 상태(state)를 읽기 전용처럼 다루어야 합니다. 즉, React 상태에 저장된 객체는 직접 수정하지 않고 새 객체를 생성하여 설정하는 방식을 사용해야 합니다. 이를 통해 React는 상태의 변경을 감지하고 재렌더링을 수행할 수 있습니다.

객체의 변화를 안전하게 관리하기 위해, 객체를 변경하는 대신 새로운 객체를 생성하고 상태를 업데이트하는 방식으로 불변성을 유지해야 합니다. 불변성을 지키는 것은 데이터의 이전 상태를 보존하고 예기치 않은 동작을 방지하는 데 도움이 됩니다. 중첩된 객체를 업데이트할 때는 최상위 객체에서 시작하여 업데이트하고자 하는 부분까지 모든 객체의 복사본을 만들어야 하며, 이를 통해 React가 변경 사항을 감지할 수 있습니다.

Immer 라이브러리를 사용하면 객체를 보다 쉽고 간결하게 업데이트할 수 있습니다. Immer는 내부적으로 상태를 복사하고 변경사항을 기록하여 새로운 객체를 생성할 수 있게 도와줍니다.

💻 Code Examples

import { useState } from 'react';

// 기본 상태를 사용하는 예시 export default function ColorBox() { const [shape, setShape] = useState({ color: 'orange', position: { x: 0, y: 0 } });

function handleColorChange(e) { setShape(prevShape => ({ ...prevShape, color: e.target.value })); }

📝 Quiz

1. 문제: React에서 상태를 업데이트할 때 왜 기존 객체를 직접 수정해서는 안 되는가?

정답: React는 상태 변경을 감지하기 위해 상태가 새롭게 설정되어야 합니다. 기존 객체를 수정하면 React가 변경 사항을 인식하지 못해 재렌더링이 발생하지 않기 때문입니다.

2. 문제: 중첩된 객체를 업데이트할 때 필요한 단계는 무엇인가?

정답: 중첩된 객체를 업데이트하려면 먼저 최상위 객체의 복사본을 만들고, 업데이트하고자 하는 중첩된 객체의 복사본도 만들어야 하며, 이후 이를 통해 최종적으로 새로운 상태를 설정해야 합니다.

3. 문제: Immer 라이브러리를 사용할 때의 이점은 무엇인가?

정답: Immer는 개발자가 객체를 직접 변경하는 것처럼 코드를 작성할 수 있게 해주며, 내부적으로 변경사항을 기록하여 새로운 객체를 모두 생성하게 함으로써 불변성을 쉽게 관리할 수 있도록 돕습니다.
