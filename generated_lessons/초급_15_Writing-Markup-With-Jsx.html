📘 Core Concepts

JSX는 JavaScript를 확장한 문법으로, JavaScript 파일에서 HTML과 유사하게 마크업을 작성할 수 있게 해줍니다. 이 문법의 주요 규칙은 다음과 같습니다:

1. 하나의 루트 엘리먼트를 반환: 컴포넌트는 여러 개의 엘리먼트를 반환할 경우 반드시 하나의 부모 태그(예:

또는 Fragment <>)로 감싸야 합니다.

2. 모든 태그는 닫아주기: JSX에서는 모든 태그를 명시적으로 닫아줘야 합니다. 예를 들어, 태그는 로 작성해야 합니다.

3. 캐멀 케이스 어트리뷰트: JSX에서 HTML 속성은 캐멀 케이스로 작성해야 합니다. 예를 들어, class는 className으로 사용해야 합니다.

이러한 규칙은 JSX가 JavaScript 객체로 변환되어, React가 컴포넌트를 제대로 이해하고 렌더링할 수 있도록 도와줍니다.

📝 Quiz

1. 문제: JSX에서 컴포넌트가 반환해야 할 것은 무엇인가요?

정답: JSX에서는 하나의 루트 엘리먼트만을 반환해야 합니다. 여러 엘리먼트를 반환하고 싶다면 반드시 부모 태그로 감싸야 합니다.

2. 문제: JSX에서 class 속성을 어떻게 작성해야 하나요?

정답: JSX에서는 class 속성이 아닌 className 속성을 사용해야 합니다. 이는 JSX가 JavaScript 객체로 변환되기 때문에 class가 예약어이기 때문입니다.

3. 문제: JSX에서 자동 닫히는 태그는 어떻게 작성해야 하나요?

정답: 자동 닫히는 태그는 항상 슬래시(/)를 추가하여 형태로 작성해야 합니다. 예를 들어, 와 같이 작성합니다.
