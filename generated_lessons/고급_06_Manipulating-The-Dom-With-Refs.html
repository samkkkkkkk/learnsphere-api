🚀 Manipulating The Dom With Refs 마스터하기 (고급)

📘 Core Concepts

refs는 React에서 DOM 노드에 접근하기 위해 사용됩니다. useRef hook을 사용하여 React가 관리하는 DOM 요소를 참조할 수 있으며, 이를 통해 DOM에 직접 조작을 수행할 수 있습니다. useRef는 컴포넌트의 렌더링 사이에 유지되는 변경 가능한 레퍼런스를 반환하며, current 프로퍼티를 통해 해당 DOM 노드에 접근하게 됩니다. refs는 일반적으로 포커스, 스크롤 위치를 조정하거나 브라우저 API 호출과 같은 비 파괴적인 상황에서 사용됩니다. 하지만 다른 컴포넌트에 있는 DOM 노드에 접근할 때는 ref를 prop처럼 전달해야 하며, 반드시 주의 깊게 다루어야 합니다. React의 상태 관리 시스템과 충돌을 피하기 위해, 꼭 필요한 경우에만 DOM을 직접 수정해야 합니다.

📝 Quiz

1. 문제: useRef를 사용하여 refs를 선언하였을 때, current 속성의 초기 값은 무엇인가요?

정답: null. useRef는 초기로 null 값을 가진 객체를 반환합니다. 이후 React가 DOM 노드를 생성할 때 해당 노드에 대한 참조를 current에 설정합니다.

2. 문제: 여러 개의 DOM 노드를 관리해야 할 때 refs를 어떻게 설정해야 하나요?

정답: ref 콜백을 사용해야 합니다. ref 콜백을 사용하면 DOM 노드에 대한 참조를 정리할 수 있는 방법으로 배열이나 Map과 같은 데이터 구조를 통해 관리할 수 있습니다.

3. 문제: React에서 DOM 노드를 직접 수정할 때 주의해야 할 점은 무엇인가요?

정답: React가 관리하는 DOM 노드를 직접 수정하는 것은 가능하면 피해야 합니다. DOM을 직접 조작하면 React의 상태와 충돌할 수 있으며, 그런 경우 시각적 이상 현상이 발생할 수 있습니다.
