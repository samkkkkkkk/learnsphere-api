🚀 Preserving And Resetting State 마스터하기 (중급)

📘 Core Concepts

React에서 각 컴포넌트는 독립적인 state를 가지고 있으며, 이 state는 컴포넌트가 UI 트리에서 어떤 위치에 렌더링되는지에 따라 관리됩니다. 컴포넌트가 같은 위치에 렌더링될 때 React는 state를 보존하지만, 위치가 변하면 state가 초기화됩니다. 따라서 컴포넌트의 위치가 유지되면 state가 공유되고, 다른 위치에 경로를 지정하면 새로 생성됩니다.

특정 작업에서 state를 초기화하고자 할 때는 두 가지 방법이 있습니다. 첫 번째 방법은 컴포넌트를 다른 위치에서 렌더링하는 것이고, 두 번째 방법은 각 컴포넌트에 독특한 key 값을 제공하여 React에게 각각의 상태를 알려주는 것입니다. 이러한 원리를 바탕으로 state를 제어함으로써 사용자는 더 나은 경험을 할 수 있습니다.

📝 Quiz

1. 문제: 컴포넌트의 위치가 변경될 때 React는 어떻게 반응하나요?

정답: 위치가 변경되면 React는 해당 컴포넌트를 삭제하고 새로 추가된 컴포넌트를 렌더링합니다. 이때 기존의 state는 초기화됩니다.

2. 문제: 두 개의 서로 다른 컴포넌트를 같은 자리에 렌더링할 때 state는 어떻게 관리되나요?

정답: 서로 다른 컴포넌트를 같은 자리에 렌더링하면 React는 새로 렌더링된 컴포넌트에 대해 state를 초기화합니다. 컴포넌트가 위치가 유지되어야 state가 이전 상태를 보존할 수 있습니다.

3. 문제: state를 초기화하기 위한 두 가지 방법은 무엇인가요?

정답: 첫 번째 방법은 컴포넌트를 다른 위치에 렌더링하는 것이고, 두 번째 방법은 각각의 컴포넌트에 유일한 key 값을 제공하여 React가 각 상태를 구별할 수 있도록 하는 것입니다.
