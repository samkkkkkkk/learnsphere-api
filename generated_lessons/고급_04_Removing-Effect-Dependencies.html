🚀 Removing Effect Dependencies 마스터하기 (고급)

📘 Core Concepts

Effect에서 의존성을 제거하는 것은 React 애플리케이션을 최적화하는 중요한 기술입니다. Effect는 리액티브 값의 변화(예: props, state 등)에 반응하여 실행됩니다. 그러나 때때로 의존성이 불필요하게 설정될 수 있으며, 이는 비효율적인 렌더링이나 버그를 발생시킬 수 있습니다. 의존성을 제거하려면 먼저 해당 변수들이 코드에서 반응형 값이 아니라는 것을 입증해야 합니다. 필요하지 않은 의존성을 피하기 위해 코드를 구조적으로 재구성하고, 이벤트 핸들러와 Effect를 분리하거나, 반응형 값의 처리를 효과적으로 관리해야 합니다.

📝 Quiz

1. 문제: Effect의 의존성 목록이 무엇을 기반으로 결정되는가?

정답: Effect의 코드에서 사용되는 모든 반응형 값이 의존성 목록에 포함되어야 한다.

2. 문제: 의존성을 제거하기 위해 무엇을 해야 하는가?

정답: 해당 값이 반응형이 아님을 린터에 "증명"해야 한다. 이를 위해 값을 컴포넌트 밖으로 이동하거나 Effect 내부에서만 사용하게 한다.

3. 문제: 이벤트 핸들러 코드가 Effect 안에 있어야 하는 이유는 무엇인가?

정답: 특정 상호작용에 대한 응답으로 실행되어야 하므로, 이벤트 핸들러는 반응형 값으로서의 효과가 아니라 특정 이벤트가 발생했을 때만 실행되어야 한다.
