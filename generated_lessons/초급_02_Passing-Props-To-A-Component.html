📘 Core Concepts

React 컴포넌트는 props를 통해 서로 통신하며, 부모 컴포넌트가 자식 컴포넌트에 정보를 전달하는 방식입니다. props는 JSX 어트리뷰트를 통해 전달되며, 객체, 배열, 함수 등 모든 JavaScript 값을 포함할 수 있습니다. 부모 컴포넌트는 필요에 따라 변경 가능한 state를 사용하여 props를 업데이트할 수 있으며, 자식 컴포넌트는 이러한 props를 구조 분해 할당을 통해 사용할 수 있습니다. 주의할 점은 props는 불변성이 있기 때문에 직접적으로 수정할 수 없다는 것입니다.

📝 Quiz

1. 문제: 컴포넌트에 props를 전달하는 방법은 무엇인가요?

정답: JSX 어트리뷰트를 통해 전달한다. 예를 들어, 와 같이 사용할 수 있다.

2. 문제: props의 기본값을 지정하는 방법은 무엇인가요?

정답: 구조 분해 할당 시 변수 뒤에 =을 이용해 기본값을 할당한다. 예를 들어, size = 100과 같은 방식이다.

3. 문제: props는 왜 변경할 수 없는가?

정답: props는 불변성을 가지기 때문에, 직접적으로 수정할 수 없다. 변경이 필요할 경우, 부모 컴포넌트를 통해 새로운 props를 전달해야 한다.
