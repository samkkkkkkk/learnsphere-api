🚀 Referencing Values With Refs 마스터하기 (고급)

📘 Core Concepts

Ref는 React에서 특정 정보를 "기억"할 수 있게 해주는 기능입니다. 이를 통해 렌더링을 유발하지 않고도 컴포넌트의 값을 유지할 수 있습니다. Ref는 useRef Hook을 사용하여 생성하며, 이러한 Ref는 일반 자바스크립트 객체로 간주됩니다. 주로 DOM 엘리먼트에 접근하거나, 외부 API와 상호작용시 필요합니다.

State와의 중요한 차이점은, Ref의 값이 변경될 때 컴포넌트가 리렌더링되지 않는 반면, State는 값이 변경되면 컴포넌트가 다시 렌더링된다는 것입니다. 이를 통해 성능을 최적화하고 필요하지 않은 리렌더링을 방지할 수 있습니다.

Ref는 외부 시스템에 신경 쓰지 않고 애플리케이션 내에서 데이터를 관리하고, 필요할 때만 필요한 정보에 접근할 수 있는 효율적인 방법을 제공합니다.

💻 Code Examples

export default function Stopwatch() { const [startTime, setStartTime] = useState(null); const [now, setNow] = useState(null); const intervalRef = useRef(null);

clearInterval(intervalRef.current); intervalRef.current = setInterval(() => { setNow(Date.now()); }, 10); }


function handleStop() { clearInterval(intervalRef.current); }


let secondsPassed = 0; if (startTime != null && now != null) { secondsPassed = (now - startTime) / 1000; }


return (

📝 Quiz

1. 문제: Ref를 사용할 때의 가장 큰 장점은 무엇인가요?

정답: Ref를 사용하면 컴포넌트의 리렌더링을 유발하지 않고 값을 유지할 수 있습니다. 이는 성능 최적화에 도움이 됩니다.

2. 문제: useRef Hook은 어떤 타입의 값을 반환하나요?

정답: useRef(initialValue)는 { current: initialValue } 형태의 객체를 반환합니다. 이 객체는 후속 렌더링에서도 동일하게 유지됩니다.

3. 문제: Ref를 사용할 때 피해야 할 좋은 규칙은 무엇인가요?

정답: 렌더링 중에 ref.current를 읽거나 쓰지 말아야 합니다. 이렇게 하면 컴포넌트의 동작을 예측하기 어려워질 수 있습니다. State를 대신 사용해야 합니다.
