📘 Core Concepts

React에서 *컴포넌트*는 사용자 인터페이스(UI)의 재사용 가능한 부분입니다. 컴포넌트는 기본적으로 마크업과 로직을 함께 포함하고 있으며, 이를 통해 프로그래머는 복잡한 UI를 단순화하고 관리하기 쉽게 만듭니다. 컴포넌트는 JavaScript 함수로 정의되며, JSX 구문을 통해 HTML 구조를 반환합니다. 주의해야 할 점은 컴포넌트 이름은 항상 대문자로 시작해야 하며, 이로 인해 React는 이를 컴포넌트로 인식합니다.

컴포넌트를 정의하는 방법은 다음과 같습니다: 1. function 키워드로 컴포넌트를 정의하고, 2. return문을 사용해 JSX를 반환합니다.

예를 들어:

export default function Profile() {

📝 Quiz

1. 문제: React에서 컴포넌트는 어떻게 정의하나요?

정답: 컴포넌트는 function 키워드를 사용하여 정의하고, return문으로 JSX를 반환합니다.

2. 문제: 컴포넌트 이름의 첫 글자는 어떤 규칙을 따라야 하나요?

정답: 컴포넌트 이름은 대문자로 시작해야 합니다. 그렇지 않으면 React가 컴포넌트로 인식하지 못합니다.

3. 문제: JSX 내부에서 마크업을 한 줄로 작성할 수 있는 방식은 어떤 것인가요?

정답: JSX가 반환되는 부분을 괄호로 감싸지 않고 한 줄로 작성할 수 있습니다. 예를 들면 return ;와 같이 작성합니다.
