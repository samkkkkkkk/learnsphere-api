🚀 Sharing State Between Components 마스터하기 (중급)

📘 Core Concepts

두 컴포넌트 간에 상태를 공유하고 동기화하려면 부모 컴포넌트로 상태(state)를 끌어올리고, 자식 컴포넌트에는 props를 통해 상태와 상태를 변경하는 이벤트 핸들러를 전달해야 합니다. 이 과정을 *State 끌어올리기*라고 합니다. 상태의 단일 진리의 원천을 갖는 것은 데이타 흐름을 이해하고 관리하는 데 도움이 됩니다. 각 컴포넌트는 자신의 상태를 가질 수 있지만, 공통 부모를 통해 필요한 데이터 및 이벤트를 공유함으로써 전체 애플리케이션이 일관되게 동작하게 할 수 있습니다.

📝 Quiz

1. 문제: 상태를 끌어올린다는 것은 무엇을 의미하나요?

정답: 상태를 자식 컴포넌트에서 제거하고 가장 가까운 공통 부모 컴포넌트로 옮기는 것을 의미합니다. 이렇게 하면 여러 자식 컴포넌트가 동일한 상태를 공유할 수 있게 되어, 상태 변경 시 모든 관련 컴포넌트가 업데이트 됩니다.

2. 문제: props와 state의 차이는 무엇인가요?

정답: props는 부모 컴포넌트로부터 자식 컴포넌트에 전달되는 데이터로, 컴포넌트의 동작을 제어합니다. 반면, state는 컴포넌트 내에서 자체적으로 관리되는 데이터로, 컴포넌트의 상태를 결정하며 렌더링에 영향을 미칠 수 있습니다.

3. 문제: 제어 컴포넌트와 비제어 컴포넌트의 주된 차이는 무엇인가요?

정답: 제어 컴포넌트는 상태가 부모 컴포넌트의 props에 의해 제어되는 반면, 비제어 컴포넌트는 자신의 내부 상태를 독립적으로 관리합니다. 제어 컴포넌트는 더 유연하지만 설정이 필요하고, 비제어 컴포넌트는 사용하기 간단하지만 조정이 어렵습니다.
