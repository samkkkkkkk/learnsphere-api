🚀 Typescript 마스터하기 (고급)

📘 Core Concepts

TypeScript는 JavaScript의 슈퍼셋으로, 정적 타입을 제공하여 코드의 안전성을 높여주는 도구입니다. TypeScript를 사용하면 변수, 함수, 객체 등의 데이터 타입을 명확히 정의하고, 컴파일 시점에 오류를 잡을 수 있습니다. 특히 React와 함께 사용하면, props 및 state의 타입을 정의하여 코드의 가독성과 안정성을 높일 수 있습니다.

TypeScript를 React 컴포넌트와 함께 사용할 때, 주의해야 할 핵심 개념은 다음과 같습니다:

- 타입 정의: 컴포넌트의 props 또는 state에 대한 타입을 정의하여 코드의 정확성을 높일 수 있습니다. - Generic 타입: 상태 관리와 관련된 hooks(useState, useReducer 등)에 이용될 수 있는 제네릭 타입을 사용하여, 다양한 데이터 타입을 쉽게 다룰 수 있습니다. - 상속 및 인터페이스: TypeScript의 interface나 type을 사용하여 복잡한 데이터 구조를 정의할 수 있습니다.

📝 Quiz

1. 문제: TypeScript에서 Props의 타입을 정의할 때 사용하는 두 가지 주요 키워드는 무엇인가요?

정답: interface와 type입니다. 이 두 가지 키워드는 컴포넌트의 props type을 정의하는 데 사용되어, 컴포넌트의 사용 시 타입 안정성을 제공합니다.

2. 문제: useState에 타입을 명시적으로 지정하는 방법은 무엇인가요?

정답: useState(initialState) 형식으로 타입을 명시할 수 있습니다. 이는 상태의 타입을 명확히 하여, 이후의 코드에서 타입 오류를 줄이는 데 도움을 줍니다.

3. 문제: createContext() 호출 시 어떤 값을 타입으로 정의해야 하는가요?

정답: createContext(defaultValue) 형식으로 타입을 지정해야 합니다. 기본값은 종종 null일 수 있으므로, 타입 정의에 이를 반영해야 합니다.
