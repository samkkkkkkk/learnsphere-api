📘 Core Concepts

React를 사용할 때는 사용자 인터페이스를 컴포넌트라는 작은 조각으로 나누는 것이 중요합니다. 각 컴포넌트는 자신의 시각적 상태를 관리하고, 상위 컴포넌트에서 하위 컴포넌트로 데이터가 단방향으로 흐르는 방식을 갖습니다. 이러한 단방향 데이터 흐름은 앱의 상태와 UI를 명확하게 연결해주며, 복잡한 애플리케이션에서도 예측 가능한 코드를 작성할 수 있게 합니다. React에서는 정적인 UI를 먼저 구현하고, 이후에 상태를 추가하여 상호작용을 구현하는 과정을 거치는 것이 일반적입니다.

📝 Quiz

1. 문제: React에서 단방향 데이터 흐름이란 무엇을 의미하나요?

정답: React에서 단방향 데이터 흐름은 데이터가 부모 컴포넌트에서 자식 컴포넌트로만 흐르고, 자식 컴포넌트는 부모 컴포넌트의 데이터를 변경할 수 없다는 것을 의미합니다. 이는 애플리케이션의 예측 가능성을 높이고, 코드의 복잡성을 줄여줍니다.

2. 문제: State를 사용하는 이유는 무엇인가요?

정답: State는 컴포넌트가 기억해야 할 데이터의 최소 집합을 의미합니다. State를 사용하면, 상태가 변화할 때 UI를 렌더링할 수 있으며 사용자와의 상호작용이 이루어집니다. State는 주로 사용자의 입력이나 외부 데이터에 의해 변경됩니다.

3. 문제: Props와 State의 차이는 무엇인가요?

정답: Props는 부모 컴포넌트에서 자식 컴포넌트로 전달되는 데이터로, 읽기 전용입니다. 반면, State는 컴포넌트의 내부적 상태로, 컴포넌트가 직접 변경할 수 있으며, UI의 변화를 trigger합니다. Props는 부모가 관리하며, State는 자식이 자신의 상태를 관리합니다.
