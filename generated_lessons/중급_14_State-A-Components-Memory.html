📘 Core Concepts

React에서 state는 컴포넌트가 화면에 표시해야 하는 정보를 "기억"하는 방법입니다. 각 컴포넌트는 자신의 고유한 state를 가지며, 해당 state는 컴포넌트가 렌더링될 때마다 React에 의해 관리됩니다. State 변수를 사용하는 주요 이유는 사용자의 입력이나 다른 상호작용으로 인해 컴포넌트의 상태를 변경하고, 변경된 상태에 따라 UI를 업데이트하기 위함입니다.

State는 지역적이고 비공개입니다. 즉, 같은 컴포넌트를 여러 번 렌더링하더라도 각각은 독립적인 state를 가집니다. 이렇게 함으로써, 부모 컴포넌트는 자식 컴포넌트의 내부 상태를 알 수 없으며, 이는 컴포넌트의 재사용성과 독립성을 높입니다. 여러 개의 state 변수를가질 수 있으며, 이들을 useState 훅을 통해 선언하고 관리합니다.

📝 Quiz

1. 문제: 컴포넌트 내부에서 state 변수를 추가할 때 사용해야 하는 훅은 무엇인가요?

정답: useState 훅입니다. 이 훅은 컴포넌트의 state를 선언하고, 현재 값과 해당 값을 업데이트할 수 있는 함수를 반환합니다.

2. 문제: 같은 컴포넌트를 두 번 렌더링할 경우, 각 인스턴스의 state가 어떻게 되는가요?

정답: 각 인스턴스는 독립적인 state를 가지게 됩니다. 즉, 하나의 인스턴스에서 상태를 변경해도 다른 인스턴스에는 영향을 미치지 않습니다.

3. 문제: 두 개의 state 변수를 가진 컴포넌트가 있을 때, React에서 컴포넌트가 다시 렌더링될 때 상태가 어떻게 기억되는가요?

정답: React는 각 state 변수의 값을 기억하고, useState 호출의 순서에 따라 다음 상태 쌍을 반환합니다. 이렇게 함으로써 상태를 효율적으로 관리할 수 있습니다.
