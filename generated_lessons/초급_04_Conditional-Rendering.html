🚀 Conditional Rendering 마스터하기 (초급)

📘 Core Concepts

조건부 렌더링은 React에서 컴포넌트가 주어진 조건에 따라 서로 다른 내용을 표시할 수 있도록 합니다. JavaScript의 조건문을 사용하여 특정 조건이 true일 때 특정 JSX를 반환하고, 그렇지 않을 경우 다른 JSX를 반환할 수 있습니다. 이를 통해 UI의 동적인 변화를 쉽게 구현할 수 있습니다. 대표적인 조건부 렌더링 기법으로는 if 문, 삼항 조건 연산자(? :), 논리 AND 연산자(&&) 등을 사용할 수 있습니다.

    📝 Quiz

    1. 문제: 조건부 렌더링을 사용하여 true와 false에 따라 다른 JSX를 반환하려면 어떤 문법을 사용할 수 있나요?

    정답: if 문, 삼항 조건 연산자(? :), 논리 AND 연산자(&&)를 사용할 수 있습니다. 이들 문법을 통해 조건에 따라 다양한 JSX를 렌더링할 수 있습니다.

    2. 문제: 다음 코드에서 isPacked가 false일 때 어떤 값이 반환되나요? ``javascript function Item({ name, isPacked }) { return (

  • {name} {isPacked && '✅'}

    • ); }

    ` 정답: JSX 요소
  • {name}
    • 가 반환됩니다. isPacked가 false일 때, '✅' 부분이 렌더링되지 않기 때문에 체크 표시 없이 이름만 표시됩니다.

    3. 문제: 다음 삼항 조건 연산자 구문은 어떤 의미인가요?

    `javascript

    {isPacked ? 'You have packed this item.' : 'You have not packed this item.'}

    ` 정답: isPacked가 true일 경우 "You have packed this item."라는 텍스트가 렌더링되고, false`인 경우 "You have not packed this item."이라는 텍스트가 렌더링된다는 의미입니다. 즉, 조건에 따라 다른 내용을 보여주는 구조입니다.
