🚀 Reusing Logic With Custom Hooks 마스터하기 (고급)

📘 Core Concepts

커스텀 Hook은 React에서 재사용 가능한 로직을 만들기 위한 방법으로, 여러 컴포넌트 간의 중복된 코드 작성을 피할 수 있습니다. 컴포넌트 간에 상태 관리, 효과 실행 등의 로직을 공유할 수 있게 해줍니다. 커스텀 Hook을 정의할 때는 항상 use로 시작하여 React의 기본 Hook과의 구분을 명확히 해야 합니다. 커스텀 Hook은 상태 저장 로직을 공유할 수 있지만, 그 자체로 상태를 공유하지는 않으며, 각 호출은 독립적인 상태를 유지합니다. 이러한 Hook은 의존성 효과를 보다 간결하게 관리할 수 있도록 도와줍니다.

💻 Code Examples

import { useState, useEffect } from 'react';

// 커스텀 Hook: 네트워크 상태 확인 export function useOnlineStatus() { const [isOnline, setIsOnline] = useState(true); useEffect(() => { const handleOnline = () => setIsOnline(true); const handleOffline = () => setIsOnline(false);


window.addEventListener('online', handleOnline); window.addEventListener('offline', handleOffline);


return () => { window.removeEventListener('online', handleOnline); window.removeEventListener('offline', handleOffline); }; }, []);


return isOnline; }


// 컴포넌트 내에서 커스텀 Hook 사용 function StatusBar() { const isOnline = useOnlineStatus(); return 
{isOnline ? '✅ 온라인' : '❌ 연결 안 됨'}
; }

📝 Quiz

1. 문제: 커스텀 Hook을 정의할 때 주의해야 할 주된 작명 규칙은 무엇인가요?

정답: 커스텀 Hook의 이름은 항상 use로 시작해야 하며, 대문자로 시작하는 명사를 사용해야 합니다. 이는 React의 기본 Hook과의 구분을 명확히 하고, 코드 가독성을 높이는 역할을 합니다.

2. 문제: 두 개의 서로 다른 컴포넌트에서 커스텀 Hook을 사용했을 때, 상태는 어떻게 관리되나요?

정답: 각 컴포넌트는 독립적인 상태를 가지며, 커스텀 Hook을 사용하여 상태를 재사용하지만 동일한 상태 변수를 공유하지 않습니다. 각 Hook 호출 시 새로운 상태 인스턴스가 생성됩니다.

3. 문제: 커스텀 Hook을 사용할 때, state 및 effect와 관련된 어떤 문제를 해결할 수 있나요?

정답: 커스텀 Hook을 통해 상태 관리 및 사이드 이펙트의 코드를 분리하여 재사용성을 높이고, 코드의 중복을 줄이며, 컴포넌트의 가독성을 향상시킬 수 있습니다. 또한 이러한 Hook은 복잡한 로직을 추상화하여 간단한 API로 제공할 수 있게 해줍니다.
