🚀 State As A Snapshot 마스터하기 (중급)

📘 Core Concepts

React에서 state는 해당 렌더링 시점에서의 UI를 나타내는 스냅샷처럼 작용합니다. 사용자가 UI를 조작할 때, 예를 들어 버튼을 클릭하면 state가 업데이트되고 React는 새로운 버전의 UI를 렌더링합니다. 이러한 업데이트는 비동기적으로 이루어지기 때문에, 이벤트 핸들러 내부에서 state 값을 읽을 때는 해당 렌더링의 state가 고정되어 있어 예기치 않은 결과를 초래할 수 있습니다. 이는 또한 state가 비슷한 방식으로 호출되기 때문에 동일한 이벤트 핸들러가 매번 고유한 state 스냅샷을 가질 수 있게 합니다.

📝 Quiz

1. 문제: 이벤트 핸들러 내에서 setState 함수가 호출되는 경우, 해당 함수 호출 이후의 state 값은 어떻게 됩니까?

정답: 해당 렌더링의 state는 변경되지 않고, 다음 렌더링의 state에만 영향을 미칩니다.

2. 문제: 사용자가 버튼을 클릭했을 때의 상태 스냅샷은 어디에 저장됩니까?

정답: 상태는 React의 메모리에 저장되며, 각 렌더링 시점에 대한 스냅샷으로 존재합니다.

3. 문제: 아래 코드 실행 결과 alert는 어떤 값을 보여줍니까? ``javascript setTimeout(() => { alert(number); }, 3000);

` 정답: alert은 항상 해당 렌더링에서의 state` 스냅샷인 초기값을 보여줍니다.
