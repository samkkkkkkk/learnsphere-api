🚀 Editor Setup 마스터하기 (초급)

📘 Core Concepts

개발 환경을 올바르게 설정하는 것은 코드의 가독성을 높이고 개발 속도를 향상시키는 데 매우 중요합니다. 특히, 코드 에디터는 개발자의 주요 도구로 사용되며, 많은 기능들을 통해 코드를 보다 효율적으로 작성할 수 있도록 돕습니다.

가장 인기 있는 에디터 중 하나는 [VS Code](https://code.visualstudio.com/)로, 다양한 확장 기능을 통해 개발 환경을 커스터마이즈 할 수 있습니다. 에디터의 핵심 기능으로는 코드 린팅(Linting)과 코드 포맷팅(Formatting)이 있습니다. 린팅은 코드의 오류를 실시간으로 감지하며, 포맷팅은 일관된 코드 스타일을 유지할 수 있도록 도와줍니다.

💻 Code Examples

다음은 VS Code에서 ESLint와 Prettier를 설정하는 간단한 예입니다.

# 프로젝트에서 ESLint 설치

npm install eslint eslint-config-react-app eslint-plugin-react-hooks --save-dev


# Prettier 설치 npm install prettier eslint-config-prettier --save-dev

VS Code에서 Prettier를 설치하고 설정하기: 1. VS Code 실행하기 2. 퀵오픈 사용하기 (Ctrl/Cmd+P 누르기) 3. ext install esbenp.prettier-vscode라고 입력하기 4. 엔터 누르기

저장 시 자동 포맷팅 설정하기: 1. CTRL/CMD + SHIFT + P 누르기 2. "settings"라고 입력하기 3. 엔터 누르기 4. 검색 창에서 "format on save"라고 입력하기 5. "format on save" 옵션이 체크되어 있는지 확인하기

📝 Quiz

1. 문제: VS Code의 대표적인 확장 기능 중 하나는 무엇인가요?

정답: ESLint입니다. ESLint는 코드의 오류를 실시간으로 검출하여 개발자가 즉시 문제를 해결할 수 있도록 돕습니다.

2. 문제: VS Code에서 코드 저장 시 자동으로 포맷팅을 적용하려면 어떤 설정을 해야 하나요?

정답: "format on save" 옵션을 체크해야 합니다. 이 설정을 활성화하면 파일을 저장할 때마다 자동으로 코드 포맷팅이 수행됩니다.

3. 문제: Prettier의 주요 기능은 무엇인가요?

정답: 코드의 형식을 일관되게 정리하는 것입니다. Prettier는 설정된 규칙에 따라 코드의 들여쓰기, 따옴표 형식 등을 자동으로 조정합니다.
