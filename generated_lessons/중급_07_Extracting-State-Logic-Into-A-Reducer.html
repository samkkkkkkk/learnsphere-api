🚀 Extracting State Logic Into A Reducer 마스터하기 (중급)

📘 Core Concepts

useReducer는 React에서 상태 관리를 보다 효율적으로 수행할 수 있게 해주는 훅입니다. 여러 이벤트 핸들러에서 상태 업데이트가 분산될 때, useReducer를 통해 하나의 함수로 모든 상태 업데이트 로직을 관리할 수 있습니다. 이를 통해 코드의 가독성을 높이고 디버깅을 용이하게 할 수 있습니다.

- Reducer 함수: 현재 상태와 액션 객체를 인자로 받아 새로운 상태를 반환하는 순수 함수입니다. 액션 객체는 발생한 사용자 상호작용을 설명하는 정보를 담고 있습니다.

- useReducer 사용법: 상태를 업데이트하려면 dispatch 함수를 사용해 액션 객체를 보내야 합니다. 이 액션은 reducer에 의해 처리되어 새 상태를 반환하게 됩니다.

- 상태 구조화: 여러 필드를 가진 상태를 관리할 때, reducer를 사용하는 것이 더 나은 접근 방식입니다. 각 액션은 단일 사용자 상호작용을 설명해야 하며, 버그를 낮추고 코드의 관리성을 높여줍니다.

import { useReducer } from 'react';

// 초기 상태 정의 const initialState = { tasks: [], };


// reducer 함수 정의 function tasksReducer(state, action) { switch (action.type) { case 'added': return {...state, tasks: [...state.tasks, { id: action.id, text: action.text, done: false }]}; case 'changed': return { ...state, tasks: state.tasks.map(task => task.id === action.task.id ? action.task : task ), }; case 'deleted': return { ...state, tasks: state.tasks.filter(task => task.id !== action.id), }; default: throw new Error('Unknown action: ' + action.type); } }

📝 Quiz

1. 문제: reducer 함수는 어떤 두 가지 인자를 받으며 무엇을 반환하나요?

정답: 상태(state)와 액션(action) 객체를 인자로 받고 다음 상태를 반환합니다.

2. 문제: useReducer를 사용하여 상태 업데이트를 할 때, 액션 객체에 반드시 포함되어야 할 필드는 무엇인가요?

정답: 반드시 type 필드는 포함되어야 하며, 변화를 설명하는 문자열로 사용됩니다.

3. 문제: useReducer를 사용하여 상태 관리의 이점은 무엇인가요?

정답: 가독성을 높이고, 디버깅을 용이하게 하며, 복잡한 상태 업데이트 로직을 명확히 구조화할 수 있습니다.
