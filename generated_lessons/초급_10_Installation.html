📘 Core Concepts

React를 사용하기 위해서는 먼저 프로젝트를 설정해야 합니다. 이 과정에서는 새로운 React 앱을 만드는 방법과 기존 프로젝트에 React를 추가하는 방법을 배워보겠습니다. React는 HTML, CSS, JavaScript를 사용하여 아키텍처를 구성할 수 있으며, 필요한 만큼 점진적으로 적용할 수 있도록 설계되었습니다.

React를 처음 사용해 보고 싶다면, 설치가 필요 없는 샌드박스 환경에서 시작할 수 있습니다. 또한, 로컬 환경에서 React를 시도하려면 HTML 파일을 다운로드하여 웹 브라우저와 코드 에디터에서 여는 방법이 있습니다.

📝 Quiz

1. 문제: React를 사용하기 위한 첫 번째 단계는 무엇인가요?

정답: 새로운 React 프로젝트를 시작해야 합니다. 프로젝트를 설정하는 방법을 배우는 것이 중요합니다.

2. 문제: 로컬 환경에서 React를 시도하는 방법은 무엇인가요?

정답: HTML 파일을 다운로드하고 코드 에디터와 웹 브라우저에서 열어야 합니다. 이렇게 하면 로컬에서 React를 직접 실험할 수 있습니다.

3. 문제: Create React App은 더 이상 사용되지 않는다고 하는 이유는 무엇인가요?

정답: Create React App은 공식적으로 지원 종료되었습니다. 이를 대체할 수 있는 최신 방식을 사용하는 것이 좋습니다.
