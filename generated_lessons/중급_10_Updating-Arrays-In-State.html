🚀 Updating Arrays In State 마스터하기 (중급)

📘 Core Concepts

React에서 배열은 state로 저장할 때 변경할 수 없도록 다루어야 합니다. 이는 배열을 직접 수정하는 것이 아니라, 배열의 *새로운* 버전을 생성한 후 이를 state에 설정해야 함을 의미합니다. 배열을 업데이트하기 위해서는 map(), filter(), slice()와 같은 비변경 함수들을 사용하여 새 배열을 만들어야 합니다. 이러한 접근법은 원본 state를 보호하고 React가 변경을 감지하여 렌더링을 다시 수행할 수 있도록 합니다. 또한, Immer 라이브러리를 사용하면 더욱 간결한 코드로 배열을 업데이트할 수 있습니다.

📝 Quiz

1. 문제: React에서 state로 저장할 때 배열을 어떤 방식으로 다루어야 하나요?

정답: 배열은 직접 수정해서는 안 되고, 새로운 배열을 만들어서 업데이트해야 합니다. 예를 들어, map(), filter(), 등의 비변경 함수를 사용하여 새로운 배열을 생성합니다.

2. 문제: 배열에서 항목을 삭제할 때 사용할 수 있는 함수는 무엇인가요?

정답: filter() 함수를 사용할 수 있습니다. 이 함수는 특정 조건을 만족하지 않는 항목들로 새로운 배열을 생성하여 원본 배열을 변경하지 않습니다.

3. 문제: Immer를 사용하면 어떤 이점이 있나요?

정답: Immer를 사용하면 깊은 복사를 쉽게 할 수 있어, 필드 값을 직관적으로 변경하면서 원본 state를 변경하지 않을 수 있습니다. draft 객체를 조작하여 더욱 간결한 업데이트 로직을 작성할 수 있습니다.
