🚀 Synchronizing With Effects 마스터하기 (고급)

📘 Core Concepts

useEffect 훅은 React 컴포넌트에서 렌더링 이후에 특정 부수 효과를 발생시키기 위해 사용됩니다. 효과는 네트워크 요청, 이벤트 리스너 등록 또는 DOM 조작과 같이 React 외부 시스템과 상호작용하는 데 주로 사용됩니다.

- Effect의 실행: Effect는 모든 렌더 후, 즉 컴포넌트가 화면에 표시된 이후에 실행됩니다. 이는 부수 효과를 먼저 실행하는 것이 아니라, 항상 DOM 업데이트가 먼저 수행됩니다. - 의존성 배열: 두 번째 인자로 의존성 배열을 지정함으로써 Effect가 언제 다시 실행될지 제어할 수 있습니다. 배열에 포함된 값이 변경될 때만 Effect가 다시 실행됩니다. 빈 배열 []은 컴포넌트가 처음 마운트될 때 한 번만 실행되게 만듭니다. - 클린업: Effect에서 클린업 함수를 반환함으로써, 컴포넌트가 마운트 해제될 때 혹은 Effect가 재실행되기 전에 수행해야 하는 정리 작업을 지정할 수 있습니다.

📝 Quiz

1. 문제: useEffect 훅의 기본적인 역할은 무엇인가요?

정답: useEffect는 React 컴포넌트에서 렌더링 후에 특정 부수 효과를 발생시키기 위해 사용되며, 외부 시스템과의 동기화를 처리합니다.

2. 문제: 빈 의존성 배열 []을 사용하는 경우 Effect는 언제 실행되나요?

정답: 빈 의존성 배열 []은 Effect가 컴포넌트가 처음 마운트될 때 한 번만 실행되도록 합니다.

3. 문제: 클린업 함수의 주 목적은 무엇인가요?

정답: 클린업 함수는 컴포넌트가 마운트 해제될 때 혹은 Effect가 재실행되기 전에 수행해야 하는 정리 작업을 수행합니다. 이를 통해 리소스 누수 및 불필요한 연결이 발생하는 것을 방지합니다.
