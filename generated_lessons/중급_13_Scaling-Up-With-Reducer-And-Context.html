🚀 Scaling Up With Reducer And Context 마스터하기 (중급)

📘 Core Concepts

reducer와 context를 결합하면 React 컴포넌트 간의 state 관리가 간편해집니다. useReducer Hook을 사용하여 state 업데이트 로직을 통합하고, Context API를 통해 하위 컴포넌트에 prop drilling 없이 필요한 state와 dispatch 함수를 제공할 수 있습니다. 이러한 방식은 복잡한 애플리케이션에서도 간결한 데이터 처리와 관리가 가능하도록 도와줍니다.

1. Reducer: state 변경 로직을 작성하여 다양한 action에 따라 state를 업데이트합니다. 단일 함수로 모든 상태 변경을 처리하므로 관리가 용이합니다. 2. Context: 깊은 컴포넌트 트리에서 데이터를 공유할 수 있게 해줍니다. 이를 통해 prop을 통해 데이터를 전달할 필요 없이 필요한 컴포넌트에서 context를 사용해 데이터를 직접 접근할 수 있습니다. 3. TasksProvider: TasksContext와 TasksDispatchContext를 설정하여 모든 하위 컴포넌트에 state와 dispatch를 제공합니다.

💻 Code Examples

import { createContext, useReducer, useContext } from 'react';

// Context 생성 export const TasksContext = createContext(null); export const TasksDispatchContext = createContext(null);


// Reducer 함수 및 초기 상태 function tasksReducer(tasks, action) { switch (action.type) { case 'added': return [...tasks, { id: action.id, text: action.text, done: false }]; case 'changed': return tasks.map(t => t.id === action.task.id ? action.task : t); case 'deleted': return tasks.filter(t => t.id !== action.id); default: throw new Error('Unknown action: ' + action.type); } }


const initialTasks = [{ id: 1, text: 'Sample Task', done: false }];

📝 Quiz

1. 문제: reducer는 무엇을 관리하는 데 사용되나요?

정답: state 관리. reducer는 여러 action에 기반하여 state를 업데이트하는 로직을 통합하여 관리합니다.

2. 문제: Context API의 주요 장점은 무엇인가요?

정답: prop drilling 없이 데이터를 하위 컴포넌트에 전달할 수 있습니다. 이는 컴포넌트 트리가 깊어질수록 데이터 전달이 간편해지며, 코드가 더욱 깔끔해집니다.

3. 문제: TasksDispatchContext는 어떤 역할을 하나요?

정답: dispatch 함수를 제공하여 state를 업데이트하는 기능을 하위 컴포넌트에 전달합니다. 이를 통해 하위 컴포넌트가 직접 state를 수정할 수 있는 방법을 제공합니다.
