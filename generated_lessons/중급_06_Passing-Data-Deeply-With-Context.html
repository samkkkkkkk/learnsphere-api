🚀 Passing Data Deeply With Context 마스터하기 (중급)

📘 Core Concepts

Context는 부모 컴포넌트에서 자식 컴포넌트에 깊이 상관없이 정보를 전달할 수 있도록 도와줍니다. 일반적으로 props를 통해 정보를 전달하는 것이 번거롭거나 중간 컴포넌트를 지나야 할 경우, Context를 사용하면 필요한 데이터를 보다 간편하게 관리할 수 있습니다. Context를 사용하기 위해서는 세 가지 단계를 거쳐야 합니다: 1. Context 생성: createContext를 사용하여 context를 생성하고 기본값을 설정합니다. 2. Context 사용: useContext Hook을 사용하여 필요한 컴포넌트에서 context 값을 읽어옵니다. 3. Context 제공: Context Provider를 사용하여 하위 컴포넌트에 context 값을 전달합니다.

이 방식으로 하위 컴포넌트는 상위 컨텍스트의 데이터를 직접적으로 참조할 수 있게 되어, props를 직접 전달할 필요가 없어집니다.

📝 Quiz

1. 문제: Context를 사용해야 하는 이유는 무엇인가요?

정답: 중간 컴포넌트를 거치지 않고 필요한 컴포넌트에 직접적으로 데이터를 전달할 수 있기 때문입니다. 이는 props 전달의 번거로움을 줄여줍니다.

2. 문제: Context를 생성할 때 사용하는 메소드는 무엇인가요?

정답: createContext입니다. 이 메소드는 컨텍스트를 생성하며 기본값을 설정할 수 있습니다.

3. 문제: useContext Hook이 하는 역할은 무엇인가요?

정답: useContext Hook은 React 컴포넌트에서 컨텍스트의 값을 읽어오는 역할을 합니다. 이를 통해 하위 컴포넌트가 상위 컨텍스트의 값을 쉽게 접근할 수 있습니다.
