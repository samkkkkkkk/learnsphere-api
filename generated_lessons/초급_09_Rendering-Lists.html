📘 Core Concepts

리스트를 렌더링하는 것은 React에서 데이터를 표시하는 중요한 방법입니다. 배열의 각 항목을 컴포넌트로 변환하여 웹 페이지에서 사용자에게 다양한 정보나 아이템을 효과적으로 보여줄 수 있습니다. 복잡한 데이터 구조를 다룰 때, map()과 filter()와 같은 배열 메서드를 사용하여 원하는 데이터만 선택하고 이를 렌더링하는 것이 가능합니다.

리스트 항목의 각 요소는 React가 항목을 구분하고 효과적으로 업데이트할 수 있도록 key라는 고유한 속성을 줘야 합니다. key는 렌더링할 때 각 요소가 어떻게 식별되는지를 명확히 하여 DOM 업데이트를 최적화합니다. 따라서 배열의 모든 항목이 key를 가지도록 하는 것이 중요합니다.

    📝 Quiz

    1. 문제: React에서 리스트를 렌더링할 때 key가 필요한 이유는 무엇인가요?

    정답: key는 React가 각 항목을 구분하고 업데이트를 최적화하도록 돕기 위해 필요합니다. 효과적으로 변화하는 DOM을 관리하기 위해 각 항목이 고유하게 식별될 수 있어야 합니다.

    2. 문제: map() 메서드는 어떤 역할을 하나요?

    정답: map() 메서드는 배열의 각 항목을 반복하여 새로운 배열을 생성하는 데 사용됩니다. 이를 통해 배열의 데이터를 React 컴포넌트로 변환하여 렌더링할 수 있습니다.

    3. 문제: filter() 메서드를 사용하는 주된 목적은 무엇인가요?

    정답: filter() 메서드는 조건을 기반으로 배열의 항목을 선택하여 새로운 배열을 생성하는 것입니다. 특정 조건을 만족하는 항목만 남기고 나머지는 제외하여 원하는 데이터만 렌더링할 수 있습니다.
