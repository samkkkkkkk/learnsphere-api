🚀 Importing And Exporting Components 마스터하기 (초급)

📘 Core Concepts

React에서 컴포넌트를 Importing하고 Exporting하는 것은 재사용성과 코드 관리를 용이하게 만들어줍니다. 한 파일의 컴포넌트를 다른 파일에서 사용할 수 있게 하여, 더 많은 구성 요소를 효율적으로 관리할 수 있게 됩니다.

1. Root 컴포넌트: 애플리케이션의 최상위 컴포넌트를 가리키며, 일반적으로 App.js 파일에 위치합니다. 2. Default Export: 파일에서 단 한 개의 컴포넌트를 export할 때 사용합니다. export 문에서 default 키워드를 사용합니다. 3. Named Export: 여러 개의 컴포넌트를 export할 수 있도록 허용합니다. 여기서는 export 키워드를 사용하고 중괄호로 감싸서 이름을 지정합니다. 4. Import: 외부 파일에서 export된 컴포넌트를 가져올 때 사용합니다. Default export의 경우 중괄호 없이 가져오고, Named export의 경우 중괄호를 사용합니다.

📝 Quiz

1. 문제: 한 파일에서 export할 수 있는 default export의 개수는?

정답: 한 파일에서는 단 하나의 default export만 존재할 수 있습니다. 이는 JavaScript의 모듈 시스템에 따라 한 파일이 기본으로 내보낼 수 있는 값이 하나만 허용되기 때문입니다.

2. 문제: Named export와 default export의 가장 큰 차이는 무엇인가요?

정답: Named export는 여러 개의 값을 한 파일에서 export할 수 있지만, default export는 오직 하나의 값을 export할 수 있다는 점입니다. Named export는 중괄호로 감싸서 사용하고, default export는 그렇게 하지 않습니다.

3. 문제: 컴포넌트를 import할 때 Named export를 사용하는 경우 어떤 구문을 써야 하나요?

정답: Named export를 사용할 때는 중괄호를 사용하여 import해야 합니다. 예를 들어, import { Profile } from './Profile';와 같은 형식을 사용해야 합니다. 이는 가져오는 컴포넌트의 이름이 동일해야 함을 나타냅니다.
