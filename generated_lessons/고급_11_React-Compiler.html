📘 Core Concepts

React 컴파일러는 React 애플리케이션을 최적화하여 성능을 향상시키기 위한 자동화된 도구입니다. 이 컴파일러는 React의 규칙을 이해하고 활용하며, 메모이제이션을 통해 불필요한 리렌더링을 피하는 기능을 제공합니다. 함수 컴포넌트와 Hooks에서 발생할 수 있는 성능 저하를 자동으로 최소화하는 데 중점을 두고 설계되었습니다. 컴파일러는 ESLint 플러그인을 통해 코드의 규칙 위반을 감지하고 이를 사용자에게 알려줍니다.

컴파일러는 기본적으로 애플리케이션 코드의 특정 부분을 감지하고 이를 메모이제이션 처리하여 성능을 개선합니다. 자동 메모이제이션을 통해 사용자는 매번 수동으로 메모이제이션을 적용할 필요 없이, React의 최적화를 효과적으로 활용할 수 있습니다. 또한, 컴파일러는 자바스크립트 특성으로 인해 발생할 수 있는 거짓 음성(False Negatives) 문제를 인지하고, 규칙을 위반한 컴포넌트나 Hook은 최적화에서 제외할 수 있습니다.

📝 Quiz

1. 문제: React 컴파일러가 제공하는 주요 기능 중 하나는 무엇인가요?

정답: 자동 메모이제이션을 통해 컴포넌트와 Hook의 리렌더링을 최소화합니다. React 컴파일러는 성능을 개선하기 위해 필요한 리렌더링만 수행하도록 도와줍니다.

2. 문제: 기존 프로젝트에 React 컴파일러를 적용하기 위한 첫 번째 단계는 무엇인가요?

정답: 제품 코드의 작은 디렉토리에서 컴파일러를 실행해보는 것입니다. 이를 통해 컴파일러의 효과를 점진적으로 평가할 수 있습니다.

3. 문제: React 컴파일러는 React의 어떤 규칙을 위반하는 경우 해당 컴포넌트를 최적화에서 제외하나요?

정답: 컴파일러는 React의 규칙을 정적으로 검증할 수 있으며, 규칙을 위반한 경우 그 컴포넌트나 Hook을 최적화에서 안전하게 제외합니다. 따라서 코드를 최적화할 수 있는 기회를 보호합니다.
