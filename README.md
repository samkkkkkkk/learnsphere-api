# FastAPI 프로젝트

이 프로젝트는 Python 3.7+의 표준 Python 타입 힌트를 기반으로 API를 구축하기 위한 현대적이고 빠른(고성능) 웹 프레임워크인 **FastAPI**를 사용하여 구축되었습니다.

## 특징

*   **빠른 속도**: NodeJS 및 Go와 동등한 매우 높은 성능을 제공합니다 (Starlette 및 Pydantic 덕분).
*   **빠른 개발**: 기능 개발 속도를 약 200%에서 300%까지 향상시킵니다.
*   **적은 버그**: 개발자(사람)로 인한 오류를 약 40% 줄입니다.
*   **직관적**: 뛰어난 편집기 지원. 모든 곳에서 자동 완성. 디버깅 시간 단축.
*   **쉬움**: 사용하고 배우기 쉽게 설계되었습니다. 문서 읽는 시간 단축.
*   **간결함**: 코드 중복을 최소화합니다. 각 매개변수 선언에서 여러 기능을 제공합니다.
*   **견고함**: 자동 대화형 문서와 함께 프로덕션 준비 코드를 얻을 수 있습니다.
*   **표준 기반**: API를 위한 개방형 표준(이전 Swagger였던 OpenAPI 및 JSON Schema)을 기반으로 하며 호환됩니다.

## 설치

이 프로젝트를 시작하려면 먼저 Python 3.7+가 설치되어 있는지 확인하십시오. 그런 다음 필요한 종속성을 설치합니다:

```bash
pip install -r requirements.txt
```

## 애플리케이션 실행

FastAPI 애플리케이션을 실행하려면 Uvicorn을 사용하십시오:

```bash
uvicorn main:app --reload
```

이렇게 하면 개발 서버가 시작되며, `http://127.0.0.1:8000/docs`에서 API 문서를 확인할 수 있습니다.
